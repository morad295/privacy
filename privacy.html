سياسة الخصوصية لتطبيق وظائف المطاعم

توضح سياسة الخصوصية هذه كيفية تعامل تطبيق وظائف المطاعم (المطوّر بواسطة Mohamad Issa) مع بيانات المستخدمين عند استخدام التطبيق.

1. البيانات التي نجمعها

  • معلومات الحساب: البيانات الأساسية المرتبطة بحساب المستخدم عند تسجيل الدخول (مثل الاسم، البريد الإلكتروني، أو رقم الهاتف).
  • بيانات الوظائف والإعلانات: المعلومات التي يضيفها المستخدم عند نشر أو متابعة فرص العمل في المطاعم (مثل مسمى الوظيفة، اسم المطعم، المحافظة، ومعلومات التواصل).

2. الخدمات الخارجية المستخدمة

  • Firebase (Google): يُستخدم للمصادقة وتخزين بيانات التطبيق والوظائف بشكل آمن.
  • OneSignal: يُستخدم لإرسال إشعارات فورية للمستخدمين عند توفر وظائف جديدة.

3. مشاركة البيانات وحماية المعلومات

  • لا نقوم ببيع أو تأجير أو مشاركة بيانات المستخدمين الشخصية مع أطراف إعلانية خارجية.
  • نطبق إجراءات تقنية مناسبة لحماية البيانات من الوصول غير المصرح به.

4. حقوق المستخدم وحذف البيانات

  • يحق للمستخدم مراجعة بياناته أو طلب تعديلها أو حذف حسابه والبيانات المرتبطة به في أي وقت عبر التواصل مع المطوّر.
